PULSE - Homelab Observability Platformu
=========================================

VIZYON
------
Proxmox VM'lerini, servisleri (ileride Jenkins/Nexus/Kubernetes) ve logları
tek bir yerden izleyen, sorun olunca haber veren, genişleyebilir bir Go
platformu.

CEKIRDEK FIKIR: "COLLECTOR" PATTERN
------------------------------------
Farklı veri kaynakları (health check, Proxmox API, log tail) ortak bir
Collector interface'i implement eder. Merkezi bir scheduler tüm collector
tiplerini aynı şekilde çalıştırır. Yeni bir veri kaynağı eklemek sadece yeni
bir Collector implementasyonu yazmak demektir.

    type Collector interface {
        Name() string
        Collect(ctx context.Context) (Result, error)
        Interval() time.Duration
    }

Bu pattern ileride başka projelerde de ("periyodik iş çalıştır + sonucu
sakla + alert ver" ihtiyacı olan her yerde) yeniden kullanılabilir.

PAKET YAPISI (REUSABLE PARÇALAR)
----------------------------------
- internal/scheduler   -> goroutine+ticker tabanlı generic worker engine
- internal/storage     -> Postgres erişim katmanı (repository pattern)
- internal/alerting    -> eşik aşımında webhook/telegram bildirim (generic)
- internal/api         -> REST API (sonuçları sorgulama, collector durumu)
- collectors/healthcheck -> HTTP/TCP ping ile servis sağlığı
- collectors/proxmox     -> Proxmox API'den VM/LXC durumu, kaynak kullanımı
- collectors/logwatch    -> dosya tail + regex ile log event yakalama
- cmd/pulse            -> main, tüm parçaları birleştiren entrypoint
